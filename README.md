## 📌 About the Project

This is my personal portfolio website, designed and developed to showcase my technical skills, projects, and experience as an AI and Machine Learning graduate pursuing opportunities in Data Analytics.

The website provides a central place for recruiters and developers to explore my work, understand my technical background, and connect with me.

## ✨ Features

- **Modern UI** — Clean, responsive, and visually engaging design.
- **About Me** — Introduction and professional background.
- **Skills** — Overview of my technical skills and tools.
- **Projects** — Showcase of selected projects with relevant details and links.
- **Contact** — Easy access to my professional profiles and contact information.
- **Responsive Design** — Optimized for desktop and mobile screens.

## 🛠️ Built With

## ⚡ How I Built It

1. **Planning:** Defined the website sections and overall visual direction.
2. **Structure:** Created the page layout using semantic HTML.
3. **Design:** Used CSS to develop the visual identity, layouts, animations and responsive behavior.
4. **Interactivity:** Implemented JavaScript for interactive elements and navigation.
5. **Content:** Added my technical skills, professional introduction, projects and contact information.
6. **Deployment:** Published the website using Vercel and connected it to GitHub for version control.
